# Changelog

## 0.1.0 — 2026-10-25
- First release.
- Always-on rules (`~/.claude/rules/airbag.md`): security, database, bugs, performance, all-device friendliness, git, reporting.
- `/app-audit` skill with a 9-section checklist and severity-ranked report.
- Permission rules: block reading `.env` and `~/.ssh`, block force-push, ask before push and database wipes.
- Guidance file for Anthropic's `security-guidance` plugin.
- Non-destructive installers for macOS/Linux/WSL (`install.sh`) and Windows (`install.ps1`), with uninstall.
